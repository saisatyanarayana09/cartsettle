# CartSettle Production Deployment Guide

You can deploy CartSettle in either of two valid configurations:
* **Option A (All on Render)**: Both Backend (Web Service) and Frontend (Static Site) hosted on Render with a keep-alive cron job.
* **Option B (Render + Vercel)**: Backend on Render and Frontend on Vercel Edge CDN.

Both options are 100% compliant with hackathon submission guidelines.

---

## Option A: Deploy Everything on Render (100% Render)

Render allows running your Django backend as a **Web Service** and your React Vite frontend as a **Static Site** in the same account.

### 1. Deploy via Render Blueprint (Recommended, 1-Click)
1. Push your latest code to your Git repository (`main` branch).
2. Go to [dashboard.render.com](https://dashboard.render.com/) and click **New +** > **Blueprint**.
3. Select your repository (`cartsettle`).
4. Render will read [render.yaml](file:///s:/Hackathon/cartsettle/render.yaml) and automatically create both services:
   * `cartsettle-api` (Django ASGI Web Service)
   * `cartsettle-web` (React Vite Static Site)
5. Fill in the required environment variables:
   * `GEMINI_API_KEY`: Primary Gemini API Key
   * `GEMINI_API_KEY_2`: Backup Gemini API Key
   * `GROQ_API_KEY`: Groq API Key
   * `PAYPAL_CLIENT_ID`: PayPal Sandbox Client ID
   * `PAYPAL_CLIENT_SECRET`: PayPal Sandbox Secret
   * `VITE_API_URL`: `https://cartsettle-api.onrender.com/api/v1`
   * `FRONTEND_URL`: `https://cartsettle-web.onrender.com`
6. Click **Apply**.

### 2. Manual Setup on Render (Without Blueprint)

#### Backend Service:
* **Type**: Web Service
* **Name**: `cartsettle-api`
* **Root Directory**: `backend`
* **Runtime**: `Python`
* **Build Command**: `chmod +x ./build.sh && ./build.sh`
* **Start Command**: `daphne -b 0.0.0.0 -p $PORT config.asgi:application`
* **Health Check Path**: `/api/v1/store/settings/`
* **Environment Variables**:
  * `DJANGO_ENV`: `production`
  * `PYTHON_VERSION`: `3.11.9`
  * `DJANGO_SECRET_KEY`: `<auto-generated>`
  * `DATABASE_URL`: Optional (uses SQLite if omitted)
  * `GEMINI_API_KEY`: `<your-key>`
  * `GEMINI_API_KEY_2`: `<your-key>`
  * `GROQ_API_KEY`: `<your-key>`
  * `PAYPAL_CLIENT_ID`: `<your-paypal-client-id>`
  * `PAYPAL_CLIENT_SECRET`: `<your-paypal-secret>`
  * `PAYPAL_MODE`: `sandbox`
  * `FRONTEND_URL`: `https://cartsettle-web.onrender.com`

#### Frontend Service:
* **Type**: Static Site
* **Name**: `cartsettle-web`
* **Root Directory**: `frontend`
* **Build Command**: `npm install && npm run build`
* **Publish Directory**: `dist`
* **Rewrite Rule**:
  * Source: `/*`
  * Destination: `/index.html`
* **Environment Variables**:
  * `VITE_API_URL`: `https://cartsettle-api.onrender.com/api/v1`
  * `VITE_PAYPAL_CLIENT_ID`: `<your-paypal-client-id>`

## Keep-Alive Cron Job (Prevents Sleep)

Render Web Services sleep after 15 minutes of zero traffic on the free tier. Render Static Sites **never** sleep.

To prevent the backend from sleeping:
1. Go to [cron-job.org](https://cron-job.org) or [uptimerobot.com](https://uptimerobot.com) (both 100% free).
2. Create a ping job for:
   `https://cartsettle-api.onrender.com/api/v1/store/settings/`
3. Schedule: **Every 10 minutes**.
4. The service will stay awake 24/7 with zero cold start delay.
